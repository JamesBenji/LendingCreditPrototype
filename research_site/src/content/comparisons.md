## Paired bootstrap

Predict both models on the same test loans. Draw loan indices with replacement. Compute both AUCs on the same resampled loans. Subtract B from A. Repeat 500 times with seed 0 in the helper. Skip samples containing only one class. Take the 2.5th and 97.5th percentiles of the differences. {{source:notebook|paired_auc_diff — cell 20}}

Pairing matters because a difficult resampled loan affects both models. Independent resamples would add unrelated sample variation and lose the within-loan comparison.

## Result: complexity did not show a clear gain

Saved XGBoost-minus-logistic AUC difference is 0.0029. Its 95% interval is −0.0014 to 0.0073. XGBoost has a slightly higher point estimate, but the experiment did not demonstrate an improvement. An interval containing zero is not proof of identical models or equivalence. {{evidence:comparisons}}

Only the two combined-XGBoost intervals exclude zero. They support complementary ranking information in this dataset. Combined XGBoost versus LC logistic changes both model and fields. A matched benchmark would isolate field value better. These intervals ignore some temporal dependence, selection and multiple-testing uncertainty. {{source:notebook|Models in the paired comparison — cell 26}}

## The interval is not a forecast of the next cohort

The bootstrap resamples loans from this test set. It measures variation within that observed population while keeping the fitted models fixed. A future change in underwriting, maturity or input collection is not generated by those resamples. The interval is therefore evidence about the recorded comparison, not a guarantee that its ordering or size will repeat in deployment. {{source:notebook|Paired bootstrap implementation — cell 20}} {{evidence:comparisons}}
